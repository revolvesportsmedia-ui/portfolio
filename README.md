# Advay Jariwala — Portfolio

A static portfolio site with an iOS-inspired design, built with Next.js and deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the project at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects Next.js — click Deploy

No environment variables or server configuration required. The site is fully static with no user input fields.

## Stack

- Next.js 15
- React 19
- Tailwind CSS
- TypeScript
